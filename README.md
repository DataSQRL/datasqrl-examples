# DataSQRL Examples: Operational Data Systems

<!-- Definition copied word for word from POSITIONING.md in DataSQRL/sqrl. Edit it there first, then here. -->
DataSQRL is an open-source harness for agentic data engineering on operational data: agents build real-time pipelines, data APIs, and data products; a compiler verifies them.

Each example is an operational data system: a real-time pipeline, a data API, or a data product.

None of these is a dbt-style model inside a warehouse. Several land data in Iceberg for a warehouse or query engine to read.

## The examples

* **[Finance Credit Card Chatbot](finance-credit-card-chatbot)**: A data product for AI agents. A real-time pipeline enriches and analyzes credit card transactions and serves them through a data API (GraphQL and MCP) to a GenAI chatbot that answers customers' questions about their spending. The extended example adds a credit card rewards program, and a batch variant writes spending views to Iceberg.
* **[Oil & Gas Agent Automation](oil-gas-agent-automation)**: A data product built on a shared data catalog. A real-time pipeline enriches well readings and triggers an agent to analyze abnormal events for automated troubleshooting.
* **[Clickstream AI Recommendation](clickstream-ai-recommendation)**: A real-time pipeline and data API that serve personalized recommendations from clickstream data and vector content embeddings generated by an LLM.
* **[Healthcare Study](healthcare-study)**: A real-time pipeline that enriches healthcare study data, serves it through a data API, lands it in Iceberg for a warehouse or query engine to read, and publishes it to Kafka.
* **[Logistics Shipping](logistics-shipping-geodata)**: A real-time pipeline and data API for shipment tracking served to customers.
* **[IoT Sensor Metrics](iot-sensor-metrics)**: A data API that ingests sensor metrics, processes them in real-time, and serves alerts and metrics to users.
* **[Law Enforcement](law-enforcement)**: A real-time pipeline and data API that integrate driver and vehicle databases with warrant and BOLO streams.
* **[Usage Analytics](usage-analytics)**: A data API that tracks token usage per user and alerts when a user goes over the hourly limit.
* **[Getting Started Examples](getting-started-examples)**: Seven small real-time pipelines that show one connector pattern each, from Kafka to Iceberg on AWS Glue.
* **[Iceberg Data Deduplication](iceberg-data-deduplication)**: Lake maintenance for operational pipelines: batch jobs that compact and deduplicate Iceberg tables.
* **[User Defined Function](user-defined-function)**: A small tutorial that shows how to call a custom function in your SQRL script, for custom logic inside an operational pipeline.

Supporting folders:

* [`data-generator`](data-generator) generates larger datasets for experiments and benchmarks.
* [`util`](util) holds Python helpers for loading data into Kafka and reading it back.
* [`test-jobs`](test-jobs) is CI material, not an example: regression jobs that CI runs against the DataSQRL version in `sqrl.Dockerfile`.

## Build this with the DataSQRL plugin

Every example can be built by a coding agent. Install the [DataSQRL plugin](https://github.com/DataSQRL/datasqrl-plugin) in Claude Code, Codex, Cursor, or Copilot, then describe the system you want. For example:

```text
Build a DataSQRL pipeline that reads credit card transactions from Kafka, enriches them with
customer and merchant data, and serves each customer's spending by category through a GraphQL
and MCP API for a chatbot.
```

Each example README has a prompt like this one for that example.

## Running the Examples

### Prerequisites

To compile and run these examples with DataSQRL you need to have a [recent version of Docker](https://docs.docker.com/get-docker/) installed on your machine.

### DataSQRL version

The commands in this repository use `datasqrl/cmd:latest`. CI tests every example against the version pinned in [`sqrl.Dockerfile`](sqrl.Dockerfile). If an example does not run on `latest`, replace `latest` with the tag from that file.

### Running & Compiling Examples

To run the examples on Linux or MacOS, open a terminal and run the following command:
```bash
docker run -it --rm -p 8081:8081 -p 8888:8888 -p 9092:9092 -v $PWD:/workspace datasqrl/cmd:latest run [PACKAGE FILES]
```

If you are on Windows using PowerShell, you need to reference the local directory with a slightly different syntax:
```powershell
docker run -it --rm -p 8081:8081 -p 8888:8888 -p 9092:9092 -v ${PWD}:/workspace datasqrl/cmd:latest run [PACKAGE FILES]
```

Replace `[PACKAGE FILES]` with the package files of the example, base first and overlay second; later files override earlier ones. Examples that share a data catalog also pass `-r <project>` to name the project. Check the `README.md` in the respective directory for the exact command. The [DataSQRL command reference](https://docs.datasqrl.com/docs/compiler) lists every option.
We will be using the Unix syntax, so keep in mind that you have to adjust the commands slightly on Windows machines by using `${PWD}` instead.

To compile an example (without running it), use this command:
```bash
docker run --rm -v $PWD:/workspace datasqrl/cmd:latest compile [PACKAGE FILES]
```

## What is DataSQRL?

<!-- Boilerplate copied word for word from POSITIONING.md in DataSQRL/sqrl. Edit it there first, then here. -->
DataSQRL is an open-source harness for agentic data engineering on operational data. It extends coding agents with a SQL compiler, validator, and event-time simulator. Agents build real-time pipelines, data APIs, and data products on Kafka, Flink, Postgres, Iceberg, Spark, Snowflake, and DuckDB, and the compiler verifies them across every system before deployment. Apache 2.0 licensed, it runs on your infrastructure.

* The main [DataSQRL repository](https://github.com/DataSQRL/sqrl/) has the compiler and runtime used in these examples.
* The [DataSQRL documentation](https://docs.datasqrl.com) shows how to build your own project with DataSQRL.
* [How DataSQRL compares](https://docs.datasqrl.com/docs/intro/comparison) answers "is this for me?".
* The [DataSQRL plugin](https://github.com/DataSQRL/datasqrl-plugin) runs the DataSQRL agent from Claude Code, Codex, Cursor, or Copilot.
